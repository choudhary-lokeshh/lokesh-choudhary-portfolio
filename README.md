# Lokesh Choudhary | Portfolio

Personal portfolio of Lokesh Choudhary, Full Stack Developer and AI Engineer in Jaipur.

The page looks like it is being built live by a small team of cursors, the way collaborators build a page in a design tool. It is plain HTML, CSS and JavaScript, with no framework, build step or animation library. The design rules are in `DESIGN-TOKENS.md`.

## Run it

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173.

## Keyboard

- `Esc` skips the build or closes the contact window
- `R` replays the build
- `I` toggles Inspect

With reduced motion turned on, the build is skipped and the finished page shows straight away.
